# NimPurchase demo script

Target length: 45–60 seconds.

1. “Nimiq Pay makes sending NIM easy. NimPurchase makes that payment useful after checkout.”
2. Open the merchant workspace. Create a small item, set its NIM price, and show the merchant’s selected receiving account.
3. Create the checkout. Show the QR code and checkout link.
4. Open the checkout in Nimiq Pay. Show the item, merchant, and NIM amount.
5. Approve the direct NIM payment. State: “The NIM goes straight to the merchant. NimPurchase never holds it.”
6. Show “Payment sent,” then “Payment detected,” then “Purchase verified.”
7. Open the Purchase Passport. Point out the merchant, item, NIM amount, receipt details, reward stamps, and support action.
8. Return to the merchant workspace and show the verified sale.
9. Close: “Every verified NIM payment becomes a receipt, a merchant relationship, and progress toward a reward.”

Do not show private keys, seed phrases, database URLs, RPC credentials, or unnecessary transaction hashes.
