## Local cloning note

The research environment attempted to clone the selected repositories directly, but its container DNS could not resolve github.com. Repository analysis therefore used live GitHub pages and official project/showcase documentation.

When Codex CLI runs on the user's machine, it should clone or inspect any reference repository that materially helps implementation before borrowing architectural patterns.
